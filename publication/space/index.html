Install. Load. Chat offline.

  1. Install the model-bundled APK.
  2. Wait for the local model copy and checksum check.
  3. Tap Load model & start.
  4. Chat locally. No account or cloud connection is needed.

Allow space for the APK, a private model copy and installer/history overhead. APK size is not installed size.

Bring your own local model

Prefer a smaller download? The 28.9 MB small APK imports a supported GGUF from local storage. The app never downloads models.

Streaming responses, Stop, English UI, encrypted local history and adjustable output limits are included.

Built on PrismML. Integrated for Android.

PrismML announced the 2B model on October 15, 2026. Within days, GDA Labs had an Android application and a real-device offline report. This is an early Android implementation, with no world-first or earliest-port claim.

Kotlin / Compose → JNI → C++ adapter → PrismML llama.cpp → official GGUF

The pinned PrismML fork is compiled for ARM64 with Android NDK, without modifying the upstream checkout. Its backend supplies ternary operators, Hadamard transforms, hybrid attention and applicable ARM NEON kernels. GDA Labs built the application and integration. The app uses CPU inference directly, with no local HTTP server, Vulkan or cloud endpoint.

No INTERNET permission, telemetry, advertising or account is included. The source, build instructions, test status, artifact inventory and checksums are provided.

A working preview, with clear limits.

Both 0.2.3 Release APKs passed build and signature, package, permission, ARM64 and 16 KiB checks. The Release JVM suite passed 15 tests; small-APK lint reported 0 errors and 10 warnings. New-build physical-device UI/inference testing, production signing, multilingual accuracy and battery/thermal evaluation remain pending.

Long responses can reach the output budget. Choose 256, 512 or 1024 tokens on Chat for the next reply; prompt and output must fit the context. A larger limit does not guarantee a complete or accurate answer.

Local encryption does not protect against every threat, including a compromised or unlocked phone. This preview has not been independently security-audited.
