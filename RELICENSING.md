# Application license change in 0.2.3

At the project owner's direction, GDA Labs application code is released under Apache-2.0 starting with version 0.2.3. The initial GPL-3.0-only selection was made for the GDA Labs MeshMind code from which this standalone application was extracted. No Bitchat code is included. The reviewed local application history and the initial public repository history use GDA Labs authorship; commit identity alone is not a substitute for copyright ownership records.

This change covers the application code that GDA Labs is authorized to relicense. It does not relicense PrismML, model weights, AndroidX/Kotlin or any other third-party code. Preserve their licenses and notices. In particular, the PrismML runtime remains MIT, and the official model remains Apache-2.0 with its original NOTICE. The upstream snapshot is unchanged.

Earlier tags, APKs and source archives retain their original GPL-3.0-only application notices and remain historical releases. They are not replaced or retrospectively withdrawn. The new release contains rebuilt APKs and a new source/upload bundle with Apache-2.0 application notices.
